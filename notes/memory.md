# 记忆

要记住用户跨会话的记忆

## 难点

- 是否重要
- 冲突/近义
- 膨胀
- 过时
- 多用户隔离

## 解决

### Hermes Agent

针对普通单用户，通过User.md注入到system prompt，限定最大字符数，让大模型通过工具 add/replace/remove，尽可能精炼


优点：
- 只需要一个md文件，会话中即可更新（下个对话生效），不需要额外数据库
- 只可一次编辑一条，步子不大

缺点：
- 记忆多存不下，有舍弃
- 后续压缩，当前轮memory未更新，可能会忘记

### mem0

存到向量数据库+图数据库（可选），无上限，用户输入时检索
dream机制，定期整理所有记忆

优点：
- 实体抽取+向量，维度多，更灵活

缺点：
- 不设上限，无用/垃圾可能过多
- append-only，会有冲突/过时。
